# HelioSL

HelioSL is an Agentic AI-powered renewable energy intelligence and
decision-support platform designed initially for rooftop solar users
in Sri Lanka.

## Core Features

- Multi-agent AI architecture
- Renewable energy information retrieval
- RAG-based knowledge system
- Solar energy analytics
- Weather-aware recommendations
- Financial solar analysis
- Explainable AI recommendations
- Responsible AI safeguards
- Secure user management

## Academic Context

Developed for the Information Retrieval and Web Analytics module.
